# 💬 Chat Application

A sleek and modern real-time chat application built using **React**, styled with **Tailwind CSS**, and bundled with **Vite** for ultra-fast performance.

## 🚀 Live Preview

To preview the project in development:

npm install
npm run dev
After building for production:

bash
Copy
Edit
- npm run build
- npm run preview
Ensure Vite is properly installed and port 5173 is available.

# #📦 Tech Stack
React – Component-based UI development

Vite – Lightning-fast bundling and development server

Tailwind CSS – Utility-first CSS framework for modern styling

HTML/CSS/JS – Core web technologies

# #📁 Project Structure

chatapplication/
`├── public/`                # Static assets (background images, SVGs)
`├── src/   `                # Source code
`│   ├── assets/   `         # Icons and static images
`│   ├── App.jsx `           # Main App component
`│   ├── App.css `           # Custom styling
`│   ├── main.jsx     `      # Entry point
`│   └── index.css  `        # Tailwind and global styles
`├── index.html    `         # HTML template
`├── package.json  `         # Project metadata and scripts
`└── vite.config.js    `     # Vite configuration
